## 📥 Installation on Termux

Open Termux and run these commands **one by one**:

### 1. Update Termux

```bash
pkg update -y
```

### 2. Install Git

```bash
pkg install git -y
```

### 3. Download the repository

```bash
git clone https://github.com/commentreading282-prog/Camfish.git
```

### 4. Enter the folder

```bash
cd Camfish
```

### 5. Give permission to installer

```bash
chmod +x install.sh
```

### 6. Run installer

```bash
./install.sh
```

### ▶️ Start the tool

After installation:

```bash
cd ~/Camfish
./camfish.sh
```
